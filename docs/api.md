# REST API Reference

## 1. OpenAPI & Swagger Specification

The backend automatically hosts interactive OpenAPI 3.0 documentation generated by `swagger-jsdoc` and served via `swagger-ui-express`:

- **Interactive Swagger UI**: `http://localhost:5050/api-docs`
- **Raw OpenAPI JSON**: `http://localhost:5050/api-docs.json`
- **Health Check Endpoint**: `http://localhost:5050/health`

---

## 2. Standard Response Envelopes

All API endpoints return JSON conforming to a predictable response envelope.

### Success Response Envelope
```json
{
  "success": true,
  "data": {
    "id": "2d0eddef-b29d-452f-b2b5-16d94dafa5b0",
    "name": "Bahor Tantanalar Zali"
  },
  "meta": {
    "total": 8,
    "page": 1,
    "limit": 10
  }
}
```

### Error Response Envelope
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Validation failed",
    "details": [
      {
        "field": "phone",
        "message": "Phone number must match format +998XXXXXXXXX"
      }
    ]
  }
}
```

## 3. Endpoints Catalog by Module

### 1. Authentication Module (`/api/v1/auth`)

| Method | Path | Auth / Role | Description |
| :--- | :--- | :---: | :--- |
| `POST` | `/register` | Public | Register a new customer (`USER` role). |
| `POST` | `/login` | Public | Authenticate via email/username and password. |
| `POST` | `/refresh` | Public | Rotate refresh token and receive new access token. |
| `POST` | `/logout` | Public / Auth | Revoke refresh token session in database. |
| `POST` | `/send-otp` | Public / Auth | Request 6-digit email verification OTP (rate-limited). |
| `POST` | `/verify-otp`| Public / Auth | Submit 6-digit OTP code to verify email. |

### 2. User Profile Module (`/api/v1/users`)

| Method | Path | Auth / Role | Description |
| :--- | :--- | :---: | :--- |
| `GET` | `/me` | Authenticated | Retrieve current user profile and role details. |
| `PATCH`| `/me` | Authenticated | Update user first name, last name, or phone number. |

### 3. Venue Owners Management (`/api/v1/owners`)

| Method | Path | Auth / Role | Description |
| :--- | :--- | :---: | :--- |
| `POST` | `/` | `ADMIN` | Create a new venue owner account. |
| `GET` | `/` | `ADMIN` | List all venue owners with pagination. |
| `GET` | `/:id` | `ADMIN` | Get owner profile and assigned wedding halls. |

### 4. Wedding Halls Module (`/api/v1/wedding-halls`)

| Method | Path | Auth / Role | Description |
| :--- | :--- | :---: | :--- |
| `GET` | `/` | Public / Optional | Search & filter wedding halls (district, budget, capacity). |
| `GET` | `/:id` | Public / Optional | Retrieve full venue details, photos, and services. |
| `GET` | `/:id/availability` | Public / Optional | Retrieve calendar status for specified year and month. |
| `POST` | `/` | `OWNER`, `ADMIN` | Create wedding hall (`PENDING` for Owner). |
| `PATCH`| `/:id` | `OWNER`, `ADMIN` | Update wedding hall attributes (Owner restricted to own hall). |
| `PATCH`| `/:id/status` | `ADMIN` | Approve or reject wedding hall (`APPROVED` / `REJECTED`). |
| `PATCH`| `/:id/assign-owner`| `ADMIN` | Assign wedding hall to a specific venue owner. |
| `DELETE`| `/:id` | `ADMIN` | Permanently remove wedding hall and associated media. |
| `POST` | `/:id/images` | `OWNER`, `ADMIN` | Upload up to 10 photos to MinIO gallery. |
| `DELETE`| `/:id/images/:imageId` | `OWNER`, `ADMIN` | Remove photo from gallery and MinIO storage. |
| `PATCH`| `/:id/images/:imageId/primary` | `OWNER`, `ADMIN` | Set designated photo as primary listing thumbnail. |

### 5. Additional Services Module (`/api/v1/wedding-halls/:hallId/services`)

| Method | Path | Auth / Role | Description |
| :--- | :--- | :---: | :--- |
| `POST` | `/singers` | `OWNER`, `ADMIN` | Add live performer / singer package. |
| `PATCH`| `/singers/:singerId` | `OWNER`, `ADMIN` | Update singer details or pricing. |
| `DELETE`| `/singers/:singerId` | `OWNER`, `ADMIN` | Remove singer service. |
| `POST` | `/cars` | `OWNER`, `ADMIN` | Add cortege luxury vehicle package. |
| `PATCH`| `/cars/:carId` | `OWNER`, `ADMIN` | Update cortege vehicle details or pricing. |
| `DELETE`| `/cars/:carId` | `OWNER`, `ADMIN` | Remove vehicle service. |
| `POST` | `/menu` | `OWNER`, `ADMIN` | Add banquet menu package tier. |
| `PATCH`| `/menu/:menuId` | `OWNER`, `ADMIN` | Update menu tier title or pricing. |
| `DELETE`| `/menu/:menuId` | `OWNER`, `ADMIN` | Remove menu tier. |
| `PUT` | `/karnay-surnay` | `OWNER`, `ADMIN` | Set Karnay-Surnay group availability and fee. |

### 6. Bookings Module (`/api/v1/bookings`)

| Method | Path | Auth / Role | Description |
| :--- | :--- | :---: | :--- |
| `POST` | `/` | `USER` | Create booking reservation with calculated pricing. |
| `GET` | `/my` | `USER` | List personal booking reservations. |
| `GET` | `/owner` | `OWNER` | List booking reservations for owned halls. |
| `GET` | `/admin` | `ADMIN` | Audit all platform bookings with customer contacts. |
| `GET` | `/:id` | Authenticated | Inspect specific booking details (Customer, Owner, Admin). |
| `PATCH`| `/:id/cancel` | Authenticated | Cancel reservation (frees date on calendar immediately). |
| `POST` | `/:id/pay` | Authenticated | Execute simulated 20% advance payment. |

## 4. Representative Error Examples

### 400 Bad Request — Capacity Exceeded
```json
{
  "success": false,
  "error": {
    "code": "BAD_REQUEST",
    "message": "Guest count (550) exceeds maximum hall capacity (400)"
  }
}
```

### 401 Unauthorized — Expired or Missing Token
```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Authentication required. Please log in."
  }
}
```

### 403 Forbidden — Boundary Violation
```json
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "You do not have permission to manage this wedding hall"
  }
}
```

### 404 Not Found — Missing Entity
```json
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "Wedding hall with specified ID was not found"
  }
}
```

### 409 Conflict — Double Booking Race Condition
```json
{
  "success": false,
  "error": {
    "code": "BOOKING_DATE_UNAVAILABLE",
    "message": "Wedding hall is already booked for this date"
  }
}
```

### 429 Too Many Requests — Rate Limit Exceeded
```json
{
  "success": false,
  "error": {
    "code": "TOO_MANY_REQUESTS",
    "message": "Too many requests from this IP. Please try again later."
  }
}
```
